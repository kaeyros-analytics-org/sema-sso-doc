sema-router (Go)

The WhatsApp webhook processor.

How sema-router authenticates

1
Meta webhook arrives
2
Extract phone_number_id
3
Fetch credential from SSO API
4
Process message + publish to Kafka
Key Environment Variables
SSOAPIBaseURL SSO API Gateway URL for credential fetching REQUIRED
KAFKA_BROKERS Comma-separated list of Kafka brokers REQUIRED
WHATSAPP_VERIFY_TOKEN Meta webhook verification token REQUIRED
OPENAI_API_KEY OpenAI key for AI scenario items REQUIRED
