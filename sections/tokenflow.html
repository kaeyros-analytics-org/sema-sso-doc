Token Flow Diagrams

Detailed sequence diagrams for the most important flows.

Initial Login Flow
Sequence 
Browser           Frontend           Gateway             Keycloak           Redis
   |                  |                  |                    |                  |
   |-- visit /app --> |                  |                    |                  |
   |                  |-- GET /auth/check|                    |                  |
   |                  |  <-- {authenticated:false} ----------|                  |
   |                  |                  |                    |                  |
   |<-- redirect -----|  /auth/login     |                    |                  |
   |                                     |                    |                  |
   |-- GET /auth/login?redirect_uri=X -- |                    |                  |
   |                                     |-- redirect to KC -->                 |
   |<------ redirect to Keycloak --------+--------------------+                  |
   |                                                          |                  |
   |-- user credentials ---------------------------------------->               |
   |<-- authorization code -------------------------------------|                |
   |                                                                             |
   |-- GET /auth/callback?code=X -------->                                      |
   |                                     |-- exchange code -->                  |
   |                                     |<-- KC tokens ------                  |
   |                                     |-- mint gateway JWT                    |
   |                                     |-- store session ------------------>  |
   |<-- redirect to X?token=<JWT> ------+                                       |
   |                                                                             |
   |-- GET /auth/session ----------------->                                     |
   |<-- { user, token } -----------------+                                      |
Authenticated API Call Flow
Sequence 
Frontend           Backend Service       Redis (blacklist)
   |                    |                       |
   |-- GET /api/data ---|                       |
   |   Authorization: Bearer <gateway_jwt>     |
   |   x-gateway-signature: <hmac>             |
   |   x-gateway-timestamp: <ts>               |
   |   x-credential-id: <credential_id>        |
   |                    |                       |
   |                    |-- validate JWT iss === "api-gateway"
   |                    |-- validate aud includes SERVICE_ID
   |                    |-- check JTI not blacklisted --> |
   |                    |                  <-- not found --|
   |                    |-- validate HMAC signature
   |                    |-- process request
   |<-- 200 { data } ---|                       |
Token Refresh Flow
Sequence 
httpClient (frontend)      Gateway              Keycloak
   |                           |                    |
   |-- original request ------>|                    |
   |                       Backend returns 401      |
   |<-- 401 -------------------+                    |
   |                           |                    |
   |-- POST /auth/refresh-token|                    |
   |   { refresh_token: ... }  |                    |
   |                           |-- refresh KC token->
   |                           |<-- new KC tokens --+
   |                           |-- mint new gateway JWT
   |<-- { token: <new_jwt> } --|                    |
   |                           |                    |
   |-- retry original request with new token ------>|
   |<-- 200 { data } ----------|                    |
Logout Flow
Sequence 
Browser           Gateway              Redis              Keycloak
   |                  |                    |                  |
   |-- GET /auth/logout|                   |                  |
   |                  |-- blacklist JTI -->|                  |
   |                  |-- destroy session -|                  |
   |                  |-- KC logout -------------------------------->
   |<-- redirect to login page -----------+------------------+
